# André Rocha — Personal Trainer (Landing Page)

Landing page de exemplo para um personal trainer, criada como peça de portfólio. Dados, nome, depoimentos e preços são fictícios.

**[Ver demo ao vivo](#)** — publique com GitHub Pages (Settings → Pages → Deploy from branch) e cole o link aqui.

## Stack

HTML5, CSS3 e JavaScript puro — sem frameworks, sem build step. Basta abrir `index.html` ou servir a pasta com qualquer servidor estático.

## Estrutura

```
index.html
assets/
  css/style.css
  js/script.js
```

## Destaques

- Design dark com acento neon, tipografia Poppins/Inter
- Hero com contadores animados e anel de progresso em SVG
- Menu mobile, scroll suave e header com efeito de vidro (glass) ao rolar
- Carrossel de depoimentos com autoplay e paginação por dots
- Accordion de FAQ e formulário de contato com validação (client-side, sem backend)
- Totalmente responsivo (mobile / tablet / desktop) e sem dependências externas além das fontes do Google

## Rodando localmente

```bash
python3 -m http.server 8000
# abra http://localhost:8000
```
